### Basic Linux Commands
|Command|Use|Notation|
|---|---|---|
|pwd|Print working directory|pwd|
|cd|Change directory|cd **[option][ destination]** |
|ls|List file in location|ls **[option] [directory]** |
|cp|Copy file|cp **[filename] [destination]** |
|mv|Move file|mv **[option] [source] [destination]** |
|cat|Show contents of file, Concatenate|cat **[filename]** |
|less|Show content by pages|less **[filename]** |
|echo|Print a string|echo **[option] [string]** |
|touch|Create a file|touch **[filename]** |
|mkdir|Create Directory|mkdir **[options] [directory name]** |
|rm|Remove file|rm **[option] [filename]** |


### Basic Command Line Editing
You can use the following key combinations to edit and recall commands.
|Key Combination|Action|
|---|---|
|CTRL + A|Move cursor to the beginning of the command line|
|CTRL + C|Cancel currently running commands|
|CTRL + L|Clear the terminal screen|
|CTRL + W|Delete the word starting at cursor|
|CTRL + U|Clear the line i.e., Delete all words from command line
|Up and Down Arrow Keys|Recall commands|
|Ctrl+D|Log out of the current shell session, equal to typing exit or logout|
|Tab|Command or filename completion|
|Tab Tab|Shows file or command completion possibilities|
