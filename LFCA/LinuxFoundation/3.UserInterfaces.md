## 3. USER INTERFACES
 
### Introduction
- **Chapter Overview**

    The user interfaces for Linux are not built into the operating system; rather, they are layers of programs that work together to create a desktop environment. In this section, we will examine the Linux user interfaces.

- **Learning Objectives**
 
    By the end of this section, you should be able to:
    - Discuss the Command Line Interface (CLI), Graphic User Interface (GUI) and Web User Interface (WUI) for Linux.

## User Interface Types
- **Command Line Interface (CLI)**

    The command line interface, also known as the character user interface (CUI), allows the user to issue commands directly to an application or the operating system. The computer commands are given as one or more lines of text to the program or function to accomplish a specific task or set of tasks. Many advanced Linux users prefer the command line interface (CLI) to interface with the computer. We will explore command line usage when using the BASH shell. In your career as an IT Associate, conducting tasks inside of the command line will become second nature. This course will ensure you are familiar with some of the many commands needed in your job as an IT associate.

    Interaction with the operating system is done via programs, which make requests to be serviced by the Kernel through an Application Programing Interface or API. Programs can be either "compiled" into machine instructions that the operating system recognizes, or commands can be given to an interpreter that converts high level requests to machine instruction on the fly. Compiled programs are generally much faster, as all the translation to machine language is completed ahead of time. Interpreted commands are used frequently because of their simple or common language command structure. Many implementations or operating system installs use a text-based interface that employs one of the interpreted languages. This type of user interface is known as a "command line" interface, as the commands to be passed to the interpreter are typically typed into a console or text terminal interface.        

- **Graphical User Interface (GUI)**

    A graphical user interface (GUI) is an interface that has a menu, dialog boxes, and buttons that make it easy for an end-user to perform a task with the click of a mouse. IT Associates will have a GUI interface on many of the systems they work with. As an IT Associate, knowing and assisting end-users with these GUIs may be a large part of your duties. Many of the Linux desktop distributions have GUIs.

- **Desktop Environment Options**

    One of the most popular graphical desktops is the GNOME desktop. This is one of many alternative graphical desktops available in the Linux environment, such as KDE and XFCE. Since Linux uses the command line interface by default, the graphics environment is layered on top of software components that provide a comprehensive graphical environment. The layered software approach allows for changing all or some of the graphical desktop environment components for both the default user configuration or on a per-user basis. There are many desktops, and since they are a layered application, one can select from many offerings that meet the user’s requirements.

- **Web User Interface (WUI)**

    The web user interface (WUI) uses a web browser to provide access to content, servers, or applications. The web user interface allows access to systems on the cloud and configures the system remotely. Today's modern computing environment requires a browser and internet connection to access system resources on a cloud. The WUI can be used from any web-enabled device. An example of a WUI is the application cockpit.
