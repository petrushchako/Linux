## Cloud Computing Basics
### What Does Cloud Computing Mean?

Historically, the notion of cloud was used as a metaphor to represent the Internet; a cloud-shaped figure depicting the Internet was used in computer network diagrams. To find out more about the origin of the cloud, you can explore the [history of cloud computing](https://en.wikipedia.org/wiki/Cloud_computing) on Wikipedia.

Cloud computing can be referred to as the remote allocation of resources on the cloud. [The National Institute of Standard and Technology (NIST) defines cloud computing](https://www.nist.gov/news-events/news/2011/10/final-version-nist-cloud-computing-definition-published) as:

> "Cloud computing is a model for enabling ubiquitous, convenient, on-demand network access to a shared pool of configurable computing resources (e.g. networks, servers, storage, applications, and services) that can be rapidly provisioned and released with minimal management effort or service provider interaction".


### Local vs. Cloud-Based Software

Local software is installed on a device and runs directly on that device. Local software is designed to work with a specific platform—the specific operating system and hardware that must meet certain minimum or recommended requirements.

Cloud-based software runs on a dedicated server and is designed to be accessed over the Internet. We will cover cloud-based software in more detail later in this chapter.

In the past, there were limited ways to obtain software for your computer. You purchased the software from a physical retail store or had it sent in the mail. It came packaged with the installable program on CDs, DVDs, or floppy disks and an installation guide with instructions on how to install, use, and troubleshoot the program. Today, the following options are available to obtain application software:

- Purchase a packaged version at a retail store and install using removable media
- Purchase a license online and then download and install the program
- Lease the software on a subscription basis
- Download and install apps from an app store
- Download and use open source applications and software.

When you purchase a software program, you buy a license to install and use that program on your device. Some licenses allow for installation on one device only, while others allow for installation on multiple devices. In general the licensing cost is lower with cloud-based machines, as the licensee is the cloud provider. We will discuss the licensing models for later.

Platform considerations:

- Local and cloud-based software has platform-specific versions
- Microprocessors are designed in 32-bit and 64-bit architectures
- Operating systems come in 32-bit and 64-bit versions
- System requirements, such as hardware type and operating system version.

Programs can be installed from and to a number of different locations, such as a network drive, an optical drive, a USB drive, or the Internet.
