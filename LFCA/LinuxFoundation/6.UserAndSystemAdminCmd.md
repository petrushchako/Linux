# 6. USER AND SYSTEM ADMINISTRATION COMMANDS

## Introduction
### Chapter Overview

When using or administering Linux systems, commands are used all the time, for functions like changing a directory or folder, and listing the files in a directory. Using the command line provides clean and concise methods to query, display, or change the operation of a system. 

The Graphical User Interface (GUI) is very useful, providing a bridge to new things, but the GUI is usually created after the commands have been in place for some time.


### Learning Objectives
 
By the end of this chapter, you should:
- Have a good understanding of Linux commands and options.
- Know common Linux system administration commands.
- Know common network administration commands.
- Know common user administration commands.

## Linux Commands
### Why Are There So Many Commands?

People new to Linux often ask why there are so many commands, especially when some of the commands do essentially the same thing. The literally thousands of commands possible in a Linux system can be very intimidating. Here’s some good news: No, you don’t need to know all of the commands and options to those commands. When you first start out, you really only need a few commands to do your job. But do try to learn new commands and options at least once a week. After a few months, you will be surprised by how many commands and options to those commands you will know.

Why do some of them seem to do the same thing as other commands? In some cases, there may be subtle differences. Often, the output is slightly different. Sometimes, one command may be more efficient in terms of CPU, memory or I/O than other commands.

### Using a Text Terminal on a Graphical Desktop

A [terminal emulator](https://en.wikipedia.org/wiki/Terminal_emulator) program emulates (simulates) a standalone terminal within a window on the desktop. By this, we mean it behaves essentially as if you were logging into the machine at a pure text terminal with no running graphical interface. Most terminal emulator programs support multiple terminal sessions by opening additional tabs or windows.

By default, on GNOME desktop environments, the **gnome-terminal** application is used to emulate a text-mode terminal in a window. Other available terminal programs include:

- [xterm](https://en.wikipedia.org/wiki/Xterm)
- [Konsole](https://konsole.kde.org/) (default on KDE)
- [Terminator](https://terminator-gtk3.readthedocs.io/en/latest/#)

### Launching a Terminal Window

To open a terminal on any system using a recent GNOME desktop, click on **Applications > System Tools > Terminal or Applications > Utilities > Terminal**. If you do not have the **Applications** menu, you will have to install the appropriate ```gnome-shell-extension``` package and turn it on with ```gnome-tweaks```.
